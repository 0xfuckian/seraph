§ 01 — ARCHITECTURE

Three layers. One privacy set.

View docs →

Seraph's architecture spans a Monero-inspired base layer, a general-purpose private EVM, and an XMR-optimized EVM — all sharing a unified key hierarchy and anonymity set.

Base Layer

Seraph Base

Monero-inspired privacy chain with native SER + XMR support. Stealth addresses, confidential amounts, FCMP++ membership proofs. Settlement and hard-money layer.

Seraph EVM

EVM (General)

Solidity-compatible programmable private EVM. Gas in SER by default. Optional private contract state via ZK state channels.

§ 02 — FIRST-PARTY MODULES

Built-in privacy primitives.

Each module ships as a privacy-aware contract suite with first-party wallet integration. All share the same note pool and key hierarchy.

Private Stablecoins

Over-collateralized stablecoins with private mint/burn. CollateralVault, xUSD, OracleAdapter, LiquidationEngine.

AI Payments

Unlinkable payments for AI agents and metered services. ZKCreditAuthorizer proves credit remaining without revealing balance.

Private Messaging

On-chain verifiable payment requests. InvoiceRegistry with fulfillment proofs and encrypted memos.

Relayer Network

Gas abstraction — pay fees in XMR or SER while using either EVM. Intent signing, batched settlement.
