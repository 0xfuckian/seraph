[EXECUTIVE OVERVIEW]

The greatest vulnerability in on-chain privacy isn't zero-knowledge mathematics—it's the gas tank.

When a user receives funds into a pristine, zero-knowledge stealth address, they face an insurmountable cryptographic trap:
To move or interact with those funds, the stealth address must submit an EVM transaction.
To submit an EVM transaction, the address must pay native gas (e.g. ETH).
The moment the user transfers gas from their primary wallet or centralized exchange to the stealth address, chain-surveillance heuristics (Chainalysis, Arkham, Elliptic) link the two addresses forever. 

Privacy is dead before the transaction even mines.

Seraph Protocol eliminates this fundamental flaw with native Gas Abstraction via `GasRelayer.sol` (`0x8b5F2A84c7E1a37c0245a4944c6691c94488b394` on Base Sepolia).

--------------------------------------------------------------------------------
STEP 1: PRE-FUNDING THE GAS VOUCHER POOL
--------------------------------------------------------------------------------
A user (or an onboarding sponsor, employer, or dApp faucet) pre-funds execution credits into the `GasRelayer` contract:

```solidity
function fundGasVoucher(
    address feeToken,
    uint256 amount,
    bytes32 voucherCommitment
) external nonReentrant;
```

• `feeToken`: Accepted ERC-20 payment tokens (Native Seraph `$SER` or Bridged Monero `$wXMR`).
• `voucherCommitment`: A cryptographic commitment blinding the secret preimage:
  $$\text{Commitment} = \text{Keccak256}(\text{secretPreimage} \mathbin{\Vert} \text{salt})$$
• Tokens are held in the contract's collective `voucherPoolBalance[feeToken]`.

Crucially: Funding a voucher can be done from ANY public address, third-party onboarding service, or faucet. The funding source is mathematically disconnected from the subsequent caller.

--------------------------------------------------------------------------------
STEP 2: DERIVING THE UNLINKABLE VOUCHER NULLIFIER
--------------------------------------------------------------------------------
When the user desires to execute a confidential transfer or smart contract call from their stealth wallet, they compute a single-use nullifier:

$$\text{voucherNullifier} = \text{Keccak256}(\text{secretPreimage} \mathbin{\Vert} \text{nonce} \mathbin{\Vert} \text{chainID})$$

The user then signs an off-chain meta-transaction intent:
- `target`: The smart contract to interact with (e.g. `PrivacyPool`, `Launchpad`, `InvoiceRegistry`).
- `data`: The ABI-encoded calldata payload.
- `feeToken`: $SER or $wXMR.
- `feeAmount`: The fee compensation offered to the relayer.
- `voucherNullifier`: The unique 32-byte spend proof.

--------------------------------------------------------------------------------
STEP 3: ZERO-GAS ON-CHAIN EXECUTION
--------------------------------------------------------------------------------
The relayer picks up the intent from the private mempool and calls `executeWithGasAbstraction()` on-chain:

```solidity
function executeWithGasAbstraction(
    bytes32 voucherNullifier,
    address feeToken,
    uint256 feeAmount,
    address target,
    bytes calldata data
) external nonReentrant returns (bytes memory result);
```

The contract performs atomic verification and execution in a single transaction:

1. Nullifier Verification:
   Ensures `!usedVouchers[voucherNullifier]`. Marks `usedVouchers[voucherNullifier] = true`. Replay is impossible.
2. Pool Solvency Check:
   Ensures `voucherPoolBalance[feeToken] >= feeAmount`.
3. Defensive Target Guard:
   Reverts with `ForbiddenTarget()` if target is `address(0)`, `address(this)`, `$SER`, or `$wXMR`. Attackers cannot trick the relayer into draining the contract's own token reserves.
4. Payload Execution:
   Executes `(bool ok, bytes memory ret) = target.call(data)`. If the target call reverts, the entire transaction reverts.
5. Relayer Reimbursement:
   Transfers `feeAmount` of `feeToken` directly to `msg.sender` (the relayer).

Result: The stealth user paid ZERO native ETH. Their address has ZERO gas history. Their transaction was mined with complete anonymity.
